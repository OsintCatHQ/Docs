The OsintCat API gives you the lookups of the OsintCat dashboard over HTTPS, with JSON responses.

## Base URL

```
https://www.osintcat.net/api
```

Every endpoint answers `GET` (most also accept `POST`); parameters always go in the query string.

## Authentication

Send your API key in the `X-API-KEY` header with every request:

```bash
curl "https://www.osintcat.net/api/user" -H "X-API-KEY: YOUR_API_KEY"
```

Create keys in your account under **[Settings → Developer](https://www.osintcat.net/account/developer)**. A key is shown once, when you create it: store it then. Keys start with `cat_`; your account's CatID is not an API key.

When you create a key you choose when it expires: in 7, 30 or 90 days, in a year, never, or on a date you pick. An expired key is refused like a revoked one (`403`); keys are not renewed, so create a new key and delete the old one. You can rename a key at any time.

<Warning>
  Treat a key like a password. Keep it on your server, never in a website, app or public repository. If a key may have leaked, revoke it in Settings → Developer and create a new one.
</Warning>

### Scopes

Each key carries one or more scopes:

| Scope | Allows |
| --- | --- |
| `*` | Everything (the default for a new key) |
| `osint:read` | All lookups and [Modules](/api-reference/endpoint/modules) |
| `account:read` | [Account](/api-reference/endpoint/user) |
| `billing:read` | Your balance: `GET /api/_/user/balance` answers `{"balance": 12.5}` (euros) |

A request outside the key's scopes is refused with `403 insufficient_scope`.

### Allowed IP addresses

In Settings → Developer you can list the IP addresses your requests come from. With a list set, requests from any other address are refused with `403 IP_UNAUTHORIZED`. Leave the list empty to allow every address (for example for serverless platforms whose addresses change).

## Plans and daily allowance

API access is part of these plans:

| Plan | Lookups per day | API keys |
| --- | --- | --- |
| Researcher | 300 | 1 |
| Investigator | 750 | 3 |
| Max | Unlimited | 5 |

Free and Starter plans have no API access (`403 UPGRADE_REQUIRED`). Prices are on the [pricing page](https://www.osintcat.net/pricing).

- Each lookup counts once against the daily allowance, including answers served from a cache.
- The allowance resets at 00:00 UTC. [Account](/api-reference/endpoint/user) shows what is left; many lookups also return it in `_meta.lookups_left`.
- [Account](/api-reference/endpoint/user), [Modules](/api-reference/endpoint/modules) and polling a task do not count.

### When the allowance is used up

Most lookups continue at a per-lookup price charged to your account balance; the module's page in the dashboard shows the price. You are charged only when the lookup finds something, and never for a lookup that fails. Without enough balance the request is refused with `402 INSUFFICIENT_BALANCE`. Lookups that have no per-lookup price are refused with `429 LIMIT_REACHED` until the allowance resets.

[Email OSINT](/api-reference/endpoint/email-osint) is always charged to the balance and does not use the allowance. Each endpoint's page says how it is counted under **Usage**.

## Rate limits

- **3 requests per second** per account, across all endpoints.
- **5,000 requests per hour** per endpoint from one IP address.

Over a limit, the request is refused with `429 rate_limit`; the `Retry-After` header says how many seconds to wait. Keep well inside the limits: repeatedly exceeding them can pause API access for your account for a while.

## Responses

Responses are JSON. A successful lookup answers `200` even when nothing was found; the endpoint's page shows how an empty result looks. Errors carry an `error` field, usually with a `message`, and server-side failures an `error_id` you can give support.

## Errors

| Status | `error` | Meaning |
| --- | --- | --- |
| 400 | `query error` and others | A required parameter is missing or invalid. |
| 401 | `API key required` | No `X-API-KEY` header. |
| 402 | `INSUFFICIENT_BALANCE` | The lookup would be charged and your balance does not cover it. |
| 403 | `Unauthorized` / `Invalid API key` | The key does not exist, was revoked, or has expired. |
| 403 | `insufficient_scope` | The key lacks the scope this endpoint needs. |
| 403 | `UPGRADE_REQUIRED` | Your plan has no API access. |
| 403 | `ACCESS_DENIED` | Your plan does not include this module, or it is currently unavailable. [Modules](/api-reference/endpoint/modules) shows which you can use. |
| 403 | `IP_UNAUTHORIZED` | The request came from an address that is not on your allowed list. |
| 403 | `ACCOUNT_REQUIRES_VERIFICATION` | Verify your account in the dashboard first. |
| 403 | `account_frozen` | API access for the account is suspended; contact support. |
| 410 | `ENDPOINT_RETIRED` | The endpoint no longer exists. |
| 429 | `LIMIT_REACHED` | The daily allowance is used up. |
| 429 | `rate_limit` | Too many requests; see `Retry-After`. |
| 500 | `An internal error occurred.` | Something failed on our side; quote the `error_id` to support. |
| 502 / 503 / 504 | (varies) | A data source is unavailable, under maintenance, or too slow. Not charged. |

## Responsible use

Use the API only for lawful purposes such as security research, fraud prevention and investigations you are entitled to carry out, and in line with the [Terms of Service](https://www.osintcat.net/tos) and the data protection law that applies to you.
