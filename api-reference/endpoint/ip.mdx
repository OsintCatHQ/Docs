---
title: 'IP Lookup'
api: 'GET https://www.osintcat.net/api/ip'
description: 'Open ports, services and location of an IP address'
---

Returns what is known about an IP address: open ports and services seen on it, hostnames, and its location and network.

<Note>
  Results for the same address may come from a cache for up to two days.
</Note>

## Parameters

<ParamField query="query" type="string" required>
  An IPv4 or IPv6 address.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript TypeScript
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.ip.lookup({
    query: "8.8.8.8"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.ip.lookup(
    query="8.8.8.8",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.LookupIPRequest{
		Query: "8.8.8.8",
	}
	result, err := client.IP.Lookup(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Ip\Requests\LookupIpRequest;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->ip->lookup(
    new LookupIpRequest([
        'query' => '8.8.8.8',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

<ResponseField name="ipleaks" type="object">
  Services seen on the address: open ports, banners, hostnames, known vulnerabilities. `{"error": "No information available for that IP."}` when nothing was seen.
</ResponseField>
<ResponseField name="ipinfo" type="object">
  Location and network: country, region, city, coordinates, time zone, ASN and organisation.
</ResponseField>
