---
title: 'IP Lookup'
api: 'GET https://www.osintcat.net/api/ip'
description: 'Open ports, services and location of an IP address'
---

Returns what is known about an IP address: open ports and services seen on it, hostnames, and its location and network.

<Note>
  Results for the same address may come from a cache for up to two days.
</Note>

## Parameters

<ParamField query="query" type="string" required>
  An IPv4 or IPv6 address.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## Example request

<RequestExample>
```bash cURL
curl "https://www.osintcat.net/api/ip?query=8.8.8.8" \
     -H "X-API-KEY: YOUR_API_KEY"
```

```python Python

url = "https://www.osintcat.net/api/ip"

print(response.status_code, response.json())
```

## Response

<ResponseField name="ipleaks" type="object">
  Services seen on the address: open ports, banners, hostnames, known vulnerabilities. `{"error": "No information available for that IP."}` when nothing was seen.
</ResponseField>
<ResponseField name="ipinfo" type="object">
  Location and network: country, region, city, coordinates, time zone, ASN and organisation.
</ResponseField>
