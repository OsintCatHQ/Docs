---

Returns the Chess.com profile of a player (ratings, clubs) and any records about the account found in the Chess.com leak.

## Parameters

<ParamField query="query" type="string" required>
  A Chess.com username or an e-mail address.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## Response

<ResponseField name="success" type="boolean">
  `true` when the lookup ran.
</ResponseField>
<ResponseField name="found" type="boolean">
  Whether anything was found.
</ResponseField>
<ResponseField name="query" type="string">
  The query.
</ResponseField>
<ResponseField name="resolved_username" type="string">
  The username the lookup settled on.
</ResponseField>
<ResponseField name="live_profile" type="object">
  The public profile (name, country, joined, last online, followers ...), or `null`.
</ResponseField>
<ResponseField name="live_stats" type="object">
  Ratings: `rapid`, `blitz`, `bullet`, `fide` (each `null` when unrated).
</ResponseField>
<ResponseField name="live_clubs" type="array">
  Up to 10 clubs.
</ResponseField>
<ResponseField name="leak_records" type="array">
  Records from the Chess.com leak.
</ResponseField>
<ResponseField name="leak_count" type="number">
  Number of leak records.
</ResponseField>
