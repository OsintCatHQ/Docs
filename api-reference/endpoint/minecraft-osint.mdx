Searches Minecraft server leaks for one value. Use [Minecraft Player](/api-reference/endpoint/minecraft) for a profile plus leaks in one call.

## Parameters

<ParamField query="query" type="string" required>
  The value to search for.
</ParamField>

<ParamField query="type" type="string" required>
  One of `username`, `uuid`, `email`, `ip`, `password`.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript TypeScript
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.minecraft.leaks({
    query: "Notch",
    type: "username"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.minecraft.leaks(
    query="Notch",
    query_type="username",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.LeaksMinecraftRequest{
		Query: "Notch",
		QueryType: osintcat.LeaksMinecraftRequestTypeUsername,
	}
	result, err := client.Minecraft.Leaks(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Minecraft\Requests\LeaksMinecraftRequest;
use OsintCat\Minecraft\Types\LeaksMinecraftRequestType;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->minecraft->leaks(
    new LeaksMinecraftRequest([
        'query' => 'Notch',
        'queryType' => LeaksMinecraftRequestType::Username->value,
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

The matching leak records. Their fields depend on the server the leak comes from. Results may come from a cache for up to two days.

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `invalid query type` | `type` is missing or not one of the allowed values; `allowed_types` lists them. |
| 424 | `Upstream returned an empty response` | The search could not be completed; the response carries an `error_id`. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
