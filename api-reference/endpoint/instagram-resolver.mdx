description: 'Who shared an Instagram post or reel link'
---

Resolves an Instagram post or reel share link to the account that shared it and the author of the post. Profile links cannot be resolved.

## Parameters

<ParamField query="link" type="string" required>
  An Instagram post or reel share link (with its `igsh` parameter). `url` or `query` are accepted as well.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript JS & TS
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.instagram.resolveShareLink({
    link: "https://www.instagram.com/reel/Cexample/?igsh=MWexample"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.instagram.resolve_share_link(
    link="https://www.instagram.com/reel/Cexample/?igsh=MWexample",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.ResolveShareLinkInstagramRequest{
		Link: "https://www.instagram.com/reel/Cexample/?igsh=MWexample",
	}
	result, err := client.Instagram.ResolveShareLink(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```


## Response

<ResponseField name="success" type="boolean">
  `true` when resolved.
</ResponseField>
<ResponseField name="author" type="object">
  The account that posted it: `username`, `avatar`.
</ResponseField>
<ResponseField name="sharer" type="object">
  The account that shared the link: `username`, `full_name`, `id`, `avatar`.
</ResponseField>
<ResponseField name="entity_id" type="string">
  ID of the shared post.
</ResponseField>
<ResponseField name="_meta" type="object">
  Your usage after this request.
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `Provide a valid Instagram URL via ?link=...` | No link, not an Instagram link, or the link expired or points to a private post. Not charged. |
| 422 | `profile_link` | A profile link: only post and reel share links can be resolved. Not charged. |
| 424 | `(message)` | The link could not be resolved right now. Not charged. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
