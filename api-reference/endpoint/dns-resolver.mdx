title: 'DNS Resolver'
api: 'GET https://www.osintcat.net/api/dns-resolver'
description: 'Resolve hostnames to IP addresses'
---

Resolves one or more hostnames to their IP addresses.

## Parameters

<ParamField query="query" type="string" required>
  A hostname, or several separated by commas.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript TypeScript
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.dns.resolve({
    query: "example.com,osintcat.net"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.dns.resolve(
    query="example.com,osintcat.net",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.ResolveDNSRequest{
		Query: "example.com,osintcat.net",
	}
	result, err := client.DNS.Resolve(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Dns\Requests\ResolveDnsRequest;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->dns->resolve(
    new ResolveDnsRequest([
        'query' => 'example.com,osintcat.net',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

An object mapping each hostname to its IP address (`null` when it does not resolve).

<ResponseExample>
```json 200
{
  "example.com": "93.184.215.14",
  "osintcat.net": "104.21.32.1"
}
```
</ResponseExample>
