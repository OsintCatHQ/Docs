---
title: 'Discord Lookup'
api: 'GET https://www.osintcat.net/api/discord'
description: 'Search leaked Discord account records'
---

Searches leaked Discord account records. The query matches partially on the user ID, username, e-mail, phone, IP address, Steam ID and license. Up to 100 records are returned.

<Note>
  While the Discord index is under maintenance the endpoint answers `503` with an empty `results` list; nothing is charged.
</Note>

## Parameters

<ParamField query="query" type="string" required>
  A Discord user ID, username, e-mail, phone number, IP address, Steam ID or license.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## Response

<ResponseField name="query" type="string">
  The query searched for.
</ResponseField>
<ResponseField name="count" type="number">
  Number of records.
</ResponseField>
<ResponseField name="results" type="array">
  Matching records.
  <Expandable title="properties">
    <ResponseField name="user_id" type="string">
      Discord user ID.
    </ResponseField>
    <ResponseField name="username" type="string">
      Username.
    </ResponseField>
    <ResponseField name="discriminator" type="string">
      Legacy discriminator, if any.
    </ResponseField>
    <ResponseField name="email" type="string">
      E-mail.
    </ResponseField>
    <ResponseField name="phone" type="string">
      Phone number.
    </ResponseField>
    <ResponseField name="password" type="string">
      Password, if the record has one.
    </ResponseField>
    <ResponseField name="ip" type="string">
      IP address.
    </ResponseField>
    <ResponseField name="token" type="string">
      Token, if the record has one.
    </ResponseField>
    <ResponseField name="steam" type="string">
      Linked Steam ID.
    </ResponseField>
    <ResponseField name="license" type="string">
      Game license identifier.
    </ResponseField>
    <ResponseField name="source" type="string">
      Collection the record came from.
    </ResponseField>
    <ResponseField name="added_at" type="string">
      When the record was added.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 424 | `Discord search service temporarily unavailable` | The search failed. |
| 503 | `(maintenance)` | The Discord index is under maintenance. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
