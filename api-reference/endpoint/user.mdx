---
title: 'Account'
api: 'GET https://www.osintcat.net/api/user'
description: 'Your plan, its daily allowance and what is left of it today'
---

Returns the account the API key belongs to: plan, plan expiry, and how many lookups are left today.

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Does not count as a lookup.

Needs the `account:read` scope (keys with all scopes have it).

## Example request

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript JS & TS
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.account.get();
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.account.get()
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	result, err := client.Account.Get(context.Background())
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->account->get();
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

<ResponseField name="account_info" type="object">
  The account.
  <Expandable title="properties">
    <ResponseField name="username" type="string">
      Username.
    </ResponseField>
    <ResponseField name="email" type="string">
      E-mail address of the account.
    </ResponseField>
    <ResponseField name="plan" type="string">
      Current plan, e.g. `Researcher`, `Investigator`, `Max`.
    </ResponseField>
    <ResponseField name="plan_expires" type="string">
      When the plan ends (ISO 8601), `Lifetime`, or `N/A`.
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="usage" type="object">
  Today's allowance.
  <Expandable title="properties">
    <ResponseField name="request_limit_daily" type="number">
      Lookups per day on this plan (Max: unlimited, shown as a very large number).
    </ResponseField>
    <ResponseField name="requests_remaining_today" type="number">
      Lookups left today. Resets at 00:00 UTC.
    </ResponseField>
    <ResponseField name="api_access" type="boolean">
      Whether the plan includes API access.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 401 | `API key required` | No `X-API-KEY` header. |
| 403 | `Invalid API key` | The key does not exist or was revoked. |
| 403 | `insufficient_scope` | The key lacks the `account:read` scope. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
