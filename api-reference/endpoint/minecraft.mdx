description: 'Minecraft profile, name history and leaked records in one call'
---

Combines the Minecraft profile of a player (UUID, name history, capes, skins) with records about them found in Minecraft server leaks.

## Parameters

<ParamField query="query" type="string" required>
  A Minecraft username (or the value matching `type`).
</ParamField>

<ParamField query="type" type="string" default="username">
  What `query` is for the leak search: `username` (default), `uuid`, `email` or `ip`.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript JS & TS
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.minecraft.player({
    query: "Notch"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.minecraft.player(
    query="Notch",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.PlayerMinecraftRequest{
		Query: "Notch",
	}
	result, err := client.Minecraft.Player(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Minecraft\Requests\PlayerMinecraftRequest;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->minecraft->player(
    new PlayerMinecraftRequest([
        'query' => 'Notch',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

<ResponseField name="query" type="string">
  The query.
</ResponseField>
<ResponseField name="uuid" type="string">
  Minecraft UUID, or `null`.
</ResponseField>
<ResponseField name="username" type="string">
  Current username, or `null`.
</ResponseField>
<ResponseField name="name-history" type="array">
  Earlier usernames.
</ResponseField>
<ResponseField name="capes" type="array">
  Capes on the account.
</ResponseField>
<ResponseField name="skinHistory" type="array">
  Skins the account has used.
</ResponseField>
<ResponseField name="results" type="array | object">
  Records from Minecraft server leaks; `{"error": ...}` when the leak search was unavailable.
</ResponseField>
