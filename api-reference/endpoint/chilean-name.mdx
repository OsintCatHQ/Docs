Searches Chilean public records for people by name.

## Parameters

<ParamField query="query" type="string" required>
  A full or partial name.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, requests are refused with `429 LIMIT_REACHED` until it resets at 00:00 UTC.

## Example request

<RequestExample>
```bash cURL
curl "https://www.osintcat.net/api/chilean-name?query=Juan+Perez" \
     -H "X-API-KEY: YOUR_API_KEY"
```

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript TypeScript
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.chile.person({
    query: "Juan Perez"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.chile.person(
    query="Juan Perez",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.PersonChileRequest{
		Query: "Juan Perez",
	}
	result, err := client.Chile.Person(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Chile\Requests\PersonChileRequest;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->chile->person(
    new PersonChileRequest([
        'query' => 'Juan Perez',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

The matching people (RUT, full name and the public record details available for them). Results are cached for an hour.
