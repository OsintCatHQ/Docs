---
title: 'VIN Decoder'
api: 'GET https://www.osintcat.net/api/vin'
description: 'Decode VINs and look up makes, models and manufacturers'
---

Decodes vehicle identification numbers and answers catalogue questions (makes, models, manufacturers, vehicle variables). Choose what to do with `type`.

## Parameters

<ParamField query="type" type="string" default="decode">
  `decode` (default), `batch`, `wmi`, `makes`, `manufacturers`, `variables` or `canadian`.
</ParamField>

<ParamField query="query" type="string">
  The VIN (`decode`), VINs separated by new lines, up to 50 (`batch`), a WMI (`wmi`), or the make / manufacturer / variable name the chosen `search_type` needs. Not needed for `makes`+`all`, `manufacturers`+`all`/`parts`, `variables`+`list` and `canadian`.
</ParamField>

<ParamField query="model_year" type="number">
  `decode`: model year, improves accuracy.
</ParamField>

<ParamField query="extended" type="boolean">
  `decode`: `true` for the extended field set.
</ParamField>

<ParamField query="search_type" type="string">
  `makes`: `all`, `manufacturer`, `vehicletype`, `models`, `vehicletypes`. `manufacturers`: `all`, `details`, `wmis`, `parts`. `variables`: `list`, `values`.
</ParamField>

<ParamField query="year" type="number">
  `makes` with `manufacturer`/`models`, and `canadian`: model year.
</ParamField>

<ParamField query="vehicle_type" type="string">
  `makes`+`models` and `manufacturers`+`wmis`: vehicle type filter.
</ParamField>

<ParamField query="mfr_type" type="string">
  `manufacturers`+`all`: manufacturer type filter.
</ParamField>

<ParamField query="page" type="number">
  `manufacturers`+`all`/`parts`: page number.
</ParamField>

<ParamField query="parts_type" type="string">
  `manufacturers`+`parts`: CFR part, default `565`.
</ParamField>

<ParamField query="from_date" type="string">
  `manufacturers`+`parts`: start date (required there).
</ParamField>

<ParamField query="to_date" type="string">
  `manufacturers`+`parts`: end date (required there).
</ParamField>

<ParamField query="make" type="string">
  `canadian`: make.
</ParamField>

<ParamField query="model" type="string">
  `canadian`: model.
</ParamField>

<ParamField query="units" type="string">
  `canadian`: `Metric` (default) or `US`.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## Response

The decoder's answer for the chosen `type`, typically `{"Count": n, "Message": "...", "Results": [...]}`. Decoded VINs are cached for an hour.

<ResponseExample>
```json 200
{
  "Count": 1,
  "Message": "Results returned successfully",
  "Results": [
    {
      "Make": "HONDA",
      "Model": "Accord",
      "ModelYear": "2003",
      "VIN": "1HGCM82633A004352"
    }
  ]
}
```
</ResponseExample>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `query parameter is required` | `query` missing where the chosen type needs it. |
| 400 | `Maximum 50 VINs allowed` | `batch` with more than 50 VINs. |
| 400 | `Invalid query type / Invalid search_type` | Unknown `type` or `search_type`. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
