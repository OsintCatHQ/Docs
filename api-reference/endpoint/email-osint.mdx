Checks which websites and services an e-mail address is registered with and in which breaches it appears. Every request must state its purpose.

<Warning>
  A request without a purpose (parameter `purpose`, header `X-Purpose`, or `Purpose: ...` at the end of your User-Agent) is refused with `400 USER_AGENT_IDENTITY_REQUIRED`.
</Warning>

## Parameters

<ParamField query="query" type="string" required>
  The e-mail address (`email` is accepted as well).
</ParamField>

<ParamField query="purpose" type="string">
  Why you run the lookup, e.g. `fraud prevention`. Required unless sent as a header (below).
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

<ParamField header="X-Purpose" type="string">
  The purpose, instead of the `purpose` parameter.
</ParamField>

## Usage

Does not use your daily allowance. Each lookup that finds something is charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing, or fails, is not charged.

## Example request

<RequestExample>
```bash cURL
curl "https://www.osintcat.net/api/email-osint?query=user%40example.com&purpose=fraud+prevention" \
     -H "X-API-KEY: YOUR_API_KEY"
```

```python Python
import requests

url = "https://www.osintcat.net/api/email-osint"

headers = {"X-API-KEY": "YOUR_API_KEY"}

response = requests.get(url, params=params, headers=headers, timeout=60)
print(response.status_code, response.json())
```

## Response

Results for the same address may come from a cache for up to 15 minutes.

<ResponseField name="results" type="object">
  What was found.
  <Expandable title="properties">
    <ResponseField name="register" type="array">
      Services the address is registered with.
    </ResponseField>
    <ResponseField name="breach" type="array">
      Breaches the address appears in.
    </ResponseField>
    <ResponseField name="api" type="array">
      Further findings from service lookups (profile names, pictures, account details).
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `USER_AGENT_IDENTITY_REQUIRED` | No purpose given. |
| 401 | `API key required` | No `X-API-KEY` header. |
| 402 | `INSUFFICIENT_BALANCE` | Your balance does not cover the lookup. |
| 502 | `Provider Error` | The lookup could not be completed. Not charged. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
