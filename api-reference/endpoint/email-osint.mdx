Checks which websites and services an e-mail address is registered with and in which breaches it appears. Every request must state its purpose.

<Warning>
  A request without a purpose (parameter `purpose`, header `X-Purpose`, or `Purpose: ...` at the end of your User-Agent) is refused with `400 USER_AGENT_IDENTITY_REQUIRED`.
</Warning>

## Parameters

<ParamField query="query" type="string" required>
  The e-mail address (`email` is accepted as well).
</ParamField>

<ParamField query="purpose" type="string">
  Why you run the lookup, e.g. `fraud prevention`. Required unless sent as a header (below).
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

<ParamField header="X-Purpose" type="string">
  The purpose, instead of the `purpose` parameter.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript JS & TS
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.email.lookup({
    query: "user@example.com",
    purpose: "fraud prevention"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.email.lookup(
    query="user@example.com",
    purpose="fraud prevention",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.LookupEmailRequest{
		Query: "user@example.com",
		Purpose: "fraud prevention",
	}
	result, err := client.Email.Lookup(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Email\Requests\LookupEmailRequest;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

        'query' => 'user@example.com',
        'purpose' => 'fraud prevention',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

Results for the same address may come from a cache for up to 15 minutes.

<ResponseField name="results" type="object">
  What was found.
  <Expandable title="properties">
    <ResponseField name="register" type="array">
      Services the address is registered with.
    </ResponseField>
    <ResponseField name="breach" type="array">
      Breaches the address appears in.
    </ResponseField>
    <ResponseField name="api" type="array">
      Further findings from service lookups (profile names, pictures, account details).
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="_meta" type="object">
  Your usage after this request.
  <Expandable title="properties">
    <ResponseField name="plan" type="string">
      Plan id.
    </ResponseField>
    <ResponseField name="lookups_left" type="number | string">
      Lookups left today, `unlimited` on Max, or `charging` when the allowance is used up and the lookup was charged to your balance.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `USER_AGENT_IDENTITY_REQUIRED` | No purpose given. |
| 401 | `API key required` | No `X-API-KEY` header. |
| 402 | `INSUFFICIENT_BALANCE` | The allowance is used up and your balance does not cover the lookup. |
| 424 | `Provider Error` | The lookup could not be completed. Not charged. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
