---
title: 'Machine Viewer'
description: 'Search machines from stealer logs, list their files and read or download them'
api: 'GET https://www.osintcat.net/api/machine_viewer/stats'
---

Machine Viewer holds machines from stealer logs: the files that were taken from each one, and the passwords, tokens, cookies and payment cards found in them. Search for a machine, list its files, and read or download them.

<Note>
  Every Machine Viewer request counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, requests can continue at a per-lookup price charged to your balance; a search that finds nothing is not charged. Machine IDs are UUIDs; file IDs are 20 characters.
</Note>

---

## Machine Viewer statistics

```bash
GET https://www.osintcat.net/api/machine_viewer/stats
```

How many machines, files, passwords, tokens, cookies and payment cards the Machine Viewer holds.

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

**Response**

```json
{
  "total_machines": 100000,
  "total_files": 3000000,
  "total_passwords": 19000000,
  "total_unique_passwords": 13000000,
  "total_tokens": 150000,
  "total_cookies": 320000000,
  "total_credit_cards": 70000000,
  "total_size": 150000000000
}
```

```bash cURL
curl "https://www.osintcat.net/api/machine_viewer/stats" \
     -H "X-API-KEY: YOUR_API_KEY"
```

## Search machines

```bash
GET https://www.osintcat.net/api/machine_viewer/search
```

Searches machines by name, username, hostname or machine ID.

<ParamField query="query" type="string" required>
  What to search for: a name, username, hostname or machine ID.
</ParamField>

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

**Response**

```json
{
  "success": true,
  "query": "DESKTOP",
  "total": 1,
  "machines": [
    {
      "id": "742e1f66-f449-4a6c-80d5-8f5eb8e9c2b5",
      "name": "DESKTOP-EXAMPLE",
      "imported_at": "2026-08-17T01:30:15",
      "country": "DE",
      "ip": "203.0.113.7",
      "file_count": 24,
      "total_size": 1003638,
      "has_passwords": true,
      "password_count": 108,
      "unique_password_count": 50,
      "has_tokens": true,
      "token_count": 6,
      "has_cookies": true,
      "cookie_count": 7139,
      "has_credit_cards": false,
      "credit_card_count": 0
    }
  ]
}
```

```bash cURL
curl "https://www.osintcat.net/api/machine_viewer/search?query=DESKTOP" \
     -H "X-API-KEY: YOUR_API_KEY"
```

## Download a file

```bash
GET https://www.osintcat.net/api/machine_viewer/files/{file_id}/download
```

The file itself, as it was in the log.

<ParamField path="file_id" type="string" required>
  File ID, from `machineViewer.files`.
</ParamField>

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

**Response:** the file itself (`application/octet-stream`).

```bash cURL
curl "https://www.osintcat.net/api/machine_viewer/files/aB3dE5fG7hI9jK1lM3nO/download" \
     -H "X-API-KEY: YOUR_API_KEY" -o file
```

**SDK example**

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript TypeScript
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const response = await client.machineViewer.downloadFile({
    file_id: "aB3dE5fG7hI9jK1lM3nO"
});
const file = await response.arrayBuffer();
console.log(file.byteLength, "bytes");
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

data = b"".join(client.machine_viewer.download_file(
    file_id="aB3dE5fG7hI9jK1lM3nO",
))
print(len(data), "bytes")
```

```go Go

	"context"
	"fmt"
	"io"

		FileID: "aB3dE5fG7hI9jK1lM3nO",

	}
	fmt.Println(len(data), "bytes")
}
```

