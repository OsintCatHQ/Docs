---

Look up a GitHub account by its username and get the public profile.

## Parameters

<ParamField query="username" type="string" required>
  The GitHub username.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## Response

`taken` is `true` when the account exists. `ExtraData` holds what the profile shows publicly; a field the profile does not have is left out. When the lookup could not be completed, `taken` is `false` and `error` says why (for example `rate_limited`, try again later).

<ResponseField name="taken" type="boolean">
  Whether an account with this username exists.
</ResponseField>
<ResponseField name="error" type="string">
  Present only when the lookup could not be completed.
</ResponseField>
<ResponseField name="ExtraData" type="object">
  Public profile fields.
  <Expandable title="properties">
    <ResponseField name="Username" type="string">
      Login.
    </ResponseField>
    <ResponseField name="Name" type="string">
      Name.
    </ResponseField>
    <ResponseField name="Bio" type="string">
      Bio.
    </ResponseField>
    <ResponseField name="Location" type="string">
      Location.
    </ResponseField>
    <ResponseField name="Company" type="string">
      Company.
    </ResponseField>
    <ResponseField name="Blog" type="string">
      Website.
    </ResponseField>
    <ResponseField name="Email" type="string">
      Public e-mail.
    </ResponseField>
    <ResponseField name="Twitter" type="string">
      X/Twitter handle.
    </ResponseField>
    <ResponseField name="Followers" type="number">
      Followers.
    </ResponseField>
    <ResponseField name="Following" type="number">
      Following.
    </ResponseField>
    <ResponseField name="PublicRepos" type="number">
      Public repositories.
    </ResponseField>
    <ResponseField name="CreatedAt" type="string">
      Account creation.
    </ResponseField>

      Profile link.
    </ResponseField>
    <ResponseField name="Repositories" type="array">
      The 10 most recently pushed repositories (name, description, url, language, stars, forks).
    </ResponseField>
  </Expandable>
</ResponseField>
