Resolves a TikTok share link (e.g. `https://vm.tiktok.com/...`) to the account that shared it, with share details and the video.

## Parameters

<ParamField query="link" type="string" required>
  A TikTok share link. `url` or `query` are accepted as well.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>

```python Python
    link="https://vm.tiktok.com/ZMexample/",
)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.ResolveShareLinkTiktokRequest{
		Link: "https://vm.tiktok.com/ZMexample/",
	}
	result, err := client.Tiktok.ResolveShareLink(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```


## Response

<ResponseField name="success" type="boolean">
  `true` when resolved.
</ResponseField>
<ResponseField name="sharer" type="object">
  The account that shared the link: `username`, `nickname`, `avatar`, `region`, `language`, `account_created`, `follower_count`, `following_count`, `heart_count`, `video_count`, `bio`, `verified`, `private`. `resolved_via` is `sec_uid` for the sharer, or `video_author` when only the video's author could be identified.
</ResponseField>
<ResponseField name="share_info" type="object">
  The share: `shared_from`, `share_time`, `device`, `language`, `region`, `account_created`.
</ResponseField>
<ResponseField name="video" type="object">
  The video: `full_url`, `video_id`, `video_created`, `type`, `author_username`.
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `Provide a valid TikTok short link via ?link=...` | No link, or not a TikTok link. |
| 404 | `No user found for this link` | The link carries no sharer. |
| 424 | `Could not resolve link` | The link could not be resolved right now. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
