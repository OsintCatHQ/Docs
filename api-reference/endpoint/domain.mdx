---
title: 'Domain Lookup'
api: 'GET https://www.osintcat.net/api/domain'
description: 'Breach records that contain a domain'
---

Returns breach records whose e-mail addresses or URLs belong to a domain.

## Parameters

<ParamField query="query" type="string" required>
  The domain, e.g. `example.com`.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, requests are refused with `429 LIMIT_REACHED` until it resets at 00:00 UTC.

## Example request

<RequestExample>
```bash cURL
curl "https://www.osintcat.net/api/domain?query=example.com" \
     -H "X-API-KEY: YOUR_API_KEY"
```

```python Python
import requests

url = "https://www.osintcat.net/api/domain"
params = {"query": "example.com"}
headers = {"X-API-KEY": "YOUR_API_KEY"}

response = requests.get(url, params=params, headers=headers, timeout=60)
print(response.status_code, response.json())
```


## Response

An array of breach records. The fields of a record depend on the breach it comes from.

<ResponseExample>
```json 200
[
  {
    "email": "jane@example.com",
    "password": "hunter2",
    "breach": "Example 2021"
  }
]
```
</ResponseExample>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 404 | `No results found` | Nothing was found for the domain. |
| 424 | `Upstream error` | The search could not be completed; the response carries an `error_id`. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
