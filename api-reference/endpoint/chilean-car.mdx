Searches Chilean vehicle records by licence plate.

## Parameters

<ParamField query="query" type="string" required>
  The licence plate.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, requests are refused with `429 LIMIT_REACHED` until it resets at 00:00 UTC.

## Example request

<RequestExample>
```bash cURL
curl "https://www.osintcat.net/api/chilean-car?query=ABCD12" \
     -H "X-API-KEY: YOUR_API_KEY"
```

url = "https://www.osintcat.net/api/chilean-car"

print(response.status_code, response.json())

## Response

The vehicle and its registered owner details as available. An empty object when nothing was found. Results are cached for an hour.
