---
title: 'Breach Lookup'
api: 'GET https://www.osintcat.net/api/breach'
description: 'Search breach and leak indexes for an e-mail, username, phone, IP or password'
---

Searches the breach indexes (including Snusbase, LeakCheck and IntelX) for a value and returns every matching record. The search is case-insensitive.

<Note>
  Results for the same query may come from a cache for up to two days.
</Note>

## Parameters

<ParamField query="query" type="string" required>
  What to search for: an e-mail address, username, domain, phone number, IP address, name or password.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript TypeScript
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.breach.search({
    query: "user@example.com"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.breach.search(
    query="user@example.com",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.SearchBreachRequest{
		Query: "user@example.com",
	}
	result, err := client.Breach.Search(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Breach\Requests\SearchBreachRequest;

$client = new OsintCatClient(); // reads OSINTCAT_API_KEY

$result = $client->breach->search(
    new SearchBreachRequest([
        'query' => 'user@example.com',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

<ResponseField name="api" type="string">
  Always `OsintCat`.
</ResponseField>
<ResponseField name="elapsed_ms" type="number">
  Time the search took, in milliseconds.
</ResponseField>
<ResponseField name="timestamp" type="string">
  When the search ran (UTC), e.g. `Oct 6th 09:41`.
</ResponseField>
<ResponseField name="results_count" type="number">
  Number of records in `breach_data`.
</ResponseField>
<ResponseField name="breach_data" type="array">
  Matching records. The fields of a record depend on the breach it comes from (for example `email`, `username`, `password`, `hash`, `ip`, `name`, `phone`); `source_db` names the breach or index the record was found in.
</ResponseField>
<ResponseField name="_meta" type="object">
  Your usage after this request.
  <Expandable title="properties">
    <ResponseField name="plan" type="string">
      Plan id.
    </ResponseField>
    <ResponseField name="lookups_left" type="number | string">
      Lookups left today, `unlimited` on Max, or `charging` when the allowance is used up and the lookup was charged to your balance.
    </ResponseField>
  </Expandable>
</ResponseField>
