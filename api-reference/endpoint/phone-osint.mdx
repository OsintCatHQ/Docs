---

Returns what is known about a phone number: whether it is valid, the carrier and line type, the country, linked online accounts and a risk score.

## Parameters

<ParamField query="query" type="string" required>
  The phone number in international format, e.g. `+4915112345678`. Spaces and dashes are allowed.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## SDK example

The same request with the [official SDKs](/sdks). Each one reads your key from `OSINTCAT_API_KEY`.

<CodeGroup>
```typescript JS & TS
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.phone.lookup({
    query: "+4915112345678"
});
console.log(result);
```

```python Python
from osintcat import OsintCat

client = OsintCat()  # reads OSINTCAT_API_KEY

result = client.phone.lookup(
    query="+4915112345678",
)
print(result)
```

```go Go
package main

import (
	"context"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
)

func main() {
	client := osintcatclient.NewClient() // reads OSINTCAT_API_KEY
	request := &osintcat.LookupPhoneRequest{
		Query: "+4915112345678",
	}
	result, err := client.Phone.Lookup(context.Background(), request)
	if err != nil {
		panic(err)
	}
	fmt.Printf("%+v\n", result)
}
```

```php PHP
<?php

use OsintCat\OsintCatClient;

    new LookupPhoneRequest([
        'query' => '+4915112345678',
    ]),
);
echo json_encode($result, JSON_PRETTY_PRINT), PHP_EOL;
```
</CodeGroup>

## Response

<ResponseField name="module" type="string">
  Always `phone`.
</ResponseField>
<ResponseField name="query" type="string">
  The number in E.164 format.
</ResponseField>
<ResponseField name="found" type="boolean">
  Whether anything was found.
</ResponseField>
<ResponseField name="risk" type="object">
  Risk assessment.
  <Expandable title="properties">
    <ResponseField name="score" type="number">
      Score from 0 to 100, or `null`.
    </ResponseField>
    <ResponseField name="level" type="string">
      `low`, `medium`, `high` or `unknown`.
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="summary" type="array">
  The main facts as `{label, value}` pairs.
</ResponseField>
<ResponseField name="sections" type="array">
  Detailed findings, grouped (carrier, location, linked accounts ...).
</ResponseField>
<ResponseField name="raw" type="object">
  The full answer the summary is built from.
</ResponseField>
<ResponseField name="_meta" type="object">
  Your usage after this request (`plan`, `lookups_left`).
</ResponseField>

## Errors

| Status | Error | When |
| --- | --- | --- |
| 400 | `phone_*` | The number cannot be a valid phone number; `code` says why (e.g. `phone_too_short`). |
| 424 | `Upstream provider error` | The lookup could not be completed. |
| 424 | `The request timed out.` | The lookup took too long. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
