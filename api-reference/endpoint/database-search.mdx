Searches stealer-log and combo-list collections for an e-mail address or a domain.

## Parameters

<ParamField query="query" type="string" required>
  The e-mail address or domain.
</ParamField>

<ParamField query="type" type="string">
  `email` or `domain`. Detected from `query` when left out.
</ParamField>

## Headers

<ParamField header="X-API-KEY" type="string" required>
  Your API key.
</ParamField>

## Usage

Counts as one lookup against your plan's daily allowance (Max: unlimited). When the allowance is used up, the lookup can continue at a per-lookup price charged to your balance (the module's page in the dashboard shows the price); a lookup that finds nothing is not charged.

## Response

<ResponseField name="results" type="array">
  Matching entries (typically a URL, login and password, and when it was collected).
</ResponseField>
<ResponseField name="results_count" type="number">
  Number of entries.
</ResponseField>
<ResponseField name="query" type="string">
  The query searched for.
</ResponseField>
<ResponseField name="type" type="string">
  `email` or `domain`.
</ResponseField>
<ResponseField name="execution_time" type="string">
  Time the search took.
</ResponseField>
<ResponseField name="status" type="string">
  `success`.

## Errors

| Status | Error | When |
| --- | --- | --- |
| 502 | `Upstream error` | The search backend answered with an error. Not charged. |
| 504 | `timeout error` | The search backend did not answer in time. Not charged. |

See [Errors](/api-reference/introduction#errors) for the responses every endpoint can return.
