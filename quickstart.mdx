## 1. Get API access

API access is part of the Researcher, Investigator and Max plans ([pricing](https://www.osintcat.net/pricing)). [Create an account](https://www.osintcat.net/register) if you have none.

## 2. Create a key

1. Open **[Settings → Developer](https://www.osintcat.net/account/developer)**.
2. Create a key, give it a name, and tick the scopes it needs (lookups, account, balance). With none ticked, the key gets all scopes.
3. Copy the key now: it is shown only once.

<Warning>
  Keep the key on your server. Anyone with it can run lookups on your account.
</Warning>

## 3. Check the key

[Account](/api-reference/endpoint/user) does not count as a lookup:

<CodeGroup>
```bash cURL
curl "https://www.osintcat.net/api/user" -H "X-API-KEY: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://www.osintcat.net/api/user",
    headers={"X-API-KEY": "YOUR_API_KEY"},
    timeout=30,
)
response.raise_for_status()
data = response.json()
print("Plan:", data["account_info"]["plan"])
print("Lookups left today:", data["usage"]["requests_remaining_today"])
```

```javascript Node.js
const response = await fetch("https://www.osintcat.net/api/user", {
  headers: { "X-API-KEY": "YOUR_API_KEY" },
});
const data = await response.json();
console.log("Plan:", data.account_info.plan);
console.log("Lookups left today:", data.usage.requests_remaining_today);
```

```php PHP
<?php
$curl = curl_init("https://www.osintcat.net/api/user");
curl_setopt_array($curl, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => ["X-API-KEY: YOUR_API_KEY"],
]);
$data = json_decode(curl_exec($curl), true);
curl_close($curl);
echo "Plan: " . $data["account_info"]["plan"] . "\n";
echo "Lookups left today: " . $data["usage"]["requests_remaining_today"] . "\n";
```
</CodeGroup>

## 4. Run a lookup

<CodeGroup>
```bash cURL
curl "https://www.osintcat.net/api/breach?query=user@example.com" -H "X-API-KEY: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://www.osintcat.net/api/breach",
    params={"query": "user@example.com"},
    headers={"X-API-KEY": "YOUR_API_KEY"},
    timeout=60,
)
if response.status_code == 429:
    print("Slow down or wait for tomorrow's allowance:", response.json())
else:
    response.raise_for_status()
    result = response.json()
    print(result["results_count"], "records; lookups left:", result["_meta"]["lookups_left"])
```

```javascript Node.js
const url = new URL("https://www.osintcat.net/api/breach");
url.searchParams.set("query", "user@example.com");
const response = await fetch(url, { headers: { "X-API-KEY": "YOUR_API_KEY" } });
const result = await response.json();
console.log(response.status, result.results_count, result._meta);
```
</CodeGroup>

## Good practice

- **Handle `429`.** Stay under 3 requests per second and wait for `Retry-After` when a request is refused. See [Rate limits](/api-reference/introduction#rate-limits).
- **Check access first.** [Modules](/api-reference/endpoint/modules) shows which lookups your plan includes.
- **Keep keys apart.** Use one key per application, with only the scopes it needs, so you can revoke one without stopping the others.
- **Log `error_id`.** Server-side errors carry one; support can find the request with it.
