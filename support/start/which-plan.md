# Which plan is right for you?

What each plan adds, so you pay for what you actually use.

Every plan runs the same lookups in the same dashboard. What changes is how much you can search, and which tools come with it. See [Pricing](https://www.osintcat.net/pricing) for today's prices and amounts.

| If you want to | Choose |
| - | - |
| Try OsintCat first | **Free.** No card needed. |
| Search now and then, without a subscription | **Pay as you go.** Every module, including IntelX and the API, and you pay only for the lookups you run. |
| Search regularly in the dashboard | **Starter.** Adds Researches, our case files. |
| Connect your own tools | **Researcher.** Adds the API and a lot more lookups. |
| Use IntelX in the dashboard | **Investigator.** Adds IntelX and three allowed IP addresses for your API keys. |
| Search as much as your work needs | **Max.** No fixed number of lookups, everything included, unlimited case files. |
| Pay once and keep it | **Lifetime.** A generous monthly allowance under fair use, without the API. |

## Pay less

- Pay for 3, 6 or 12 months at once to save 10, 15 or 20 percent.
- Moving up costs only the difference for the rest of your period, in [Billing](https://www.osintcat.net/billing).
- Need it for a team? A company shares one plan and gives each person a seat. See [Create a company](https://www.osintcat.net/org/new).

You can also give any plan, or an amount of balance, as a gift from the [Store](https://www.osintcat.net/store).
