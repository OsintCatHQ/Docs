# Export your results

Save results as a file you can keep or share.

1. Open the result, either straight after the search or from your [history](https://www.osintcat.net/dashboard/history).
2. Choose Export and pick a format.

If one format fails, try another; for example, if an Excel file can't be made, a CSV file holds the same data.

:::note
**Handle exports with care.** An exported file can contain personal details. Store and share it only as your work allows.
:::
