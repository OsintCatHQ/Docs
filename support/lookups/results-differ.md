# Why results differ between searches

The same search can show different results over time.

Results come from records that change. A new record can appear, an old one can be corrected or removed, and a source can be unavailable for a while. So the same search can show more, fewer or different results from one day to the next.

If a result looks wrong, use the report option on that result. It reaches our team with the details we need.
