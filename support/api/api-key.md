# Create an API key

Make a key, limit what it can do, and keep it safe.

API keys are available on the Researcher plan and above, and on pay as you go.

1. Open [Developer](https://www.osintcat.net/account/developer) in your account settings.
2. Create a key. Give it a name, choose what it may do (leave everything unchecked for full access), and pick the date it expires, within the next five years.
3. Copy the key straight away. You won't be able to see it again.

Make a separate key for each app or script, so you can revoke one without stopping the others. A revoked key stops working immediately.

## Limit keys to your IP addresses

On Researcher you can allow 1 IP address, on Investigator 3, and on Max 10. Requests from other addresses are refused.
