# Make your first API request

One request from start to finish.

Send your key in the `x-api-key` header with every request. The [API documentation](https://docs.osintcat.net) lists every endpoint with its parameters and example answers.

1. Create a key on [Developer](https://www.osintcat.net/account/developer).
2. Pick an endpoint in the documentation.
3. Send the request with your key in the `x-api-key` header.

Keep your key out of code you share and out of web pages. Anyone with the key can use your plan.
