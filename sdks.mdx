The official SDKs cover every endpoint you can use today, with typed requests and responses; endpoints marked unavailable are added when they return. They are open source (MIT) and send your key in the `X-API-KEY` header.

<Tabs>
<Tab title="JS & TS">
<Steps>
<Step title="Create an API key">

Under [Settings → Developer](https://www.osintcat.net/account/developer), create a key. Choose its scopes and how long it works. The key is shown once: copy it.

</Step>
<Step title="Install the SDK">

Node.js 18 or later, Bun, Deno or Cloudflare Workers. No dependencies.

```sh
npm install osintcat
```

</Step>
<Step title="Set your key">

The SDK reads the key from the `OSINTCAT_API_KEY` environment variable. Keep it out of your code, and never ship it in a browser or mobile app.

<CodeGroup>
```sh macOS / Linux
export OSINTCAT_API_KEY="cat_..."
```

```powershell Windows
$env:OSINTCAT_API_KEY = "cat_..."
```
</CodeGroup>

</Step>
<Step title="Make your first request">

Save this as `first.mjs` and run `node first.mjs`. It shows your plan and how many lookups are left today.

```typescript first.mjs
import { OsintCatClient } from "osintcat";

const client = new OsintCatClient(); // reads OSINTCAT_API_KEY

const result = await client.account.get();
console.log(result);
```

</Step>
<Step title="Handle errors">

Every answer other than 2xx raises an error with the status code and the answer. A failure on our side or at a data source also names an `error_id` and a `request_id`: quote them to support. A lookup that fails is not charged.

```typescript
import { OsintCat, OsintCatClient, OsintCatError } from "osintcat";

const client = new OsintCatClient();

try {
    const result = await client.breach.search({ query: "user@example.com" });
    console.log(result.results_count);
} catch (err) {
    if (err instanceof OsintCat.TooManyRequestsError) {
        console.log("Daily allowance used up, or too many requests: try again later.");
    } else if (err instanceof OsintCatError) {
        // err.body carries error, message, error_id and request_id
        console.log(err.statusCode, err.body);
    } else {
        throw err;
    }
}
```

</Step>
</Steps>

Every endpoint page shows its call in each language. Source and issues: [github.com/OsintCatHQ/osintcat-typescript](https://github.com/OsintCatHQ/osintcat-typescript).

<Step title="Handle errors">

```go
package main

import (
	"context"
	"errors"
	"fmt"

	osintcat "github.com/OsintCatHQ/osintcat-go"
	osintcatclient "github.com/OsintCatHQ/osintcat-go/client"
	"github.com/OsintCatHQ/osintcat-go/core"
)

func main() {
	client := osintcatclient.NewClient()
	result, err := client.Breach.Search(context.Background(), &osintcat.SearchBreachRequest{Query: "user@example.com"})
	var limited *osintcat.TooManyRequestsError
	var apiErr *core.APIError
	switch {
	case errors.As(err, &limited):
		fmt.Println("Daily allowance used up, or too many requests: try again later.")
	case errors.As(err, &apiErr):
		// the error text carries the answer: error, message, error_id and request_id
		fmt.Println(apiErr.StatusCode, err)
	case err != nil:
		panic(err)
	default:
		fmt.Println(*result.ResultsCount)
	}
}
```

</Step>

```php
<?php
require __DIR__ . '/vendor/autoload.php';

use OsintCat\OsintCatClient;
use OsintCat\Breach\Requests\SearchBreachRequest;
use OsintCat\Exceptions\OsintcatApiException;

$client = new OsintCatClient();

try {
    $result = $client->breach->search(new SearchBreachRequest(['query' => 'user@example.com']));
    echo $result->resultsCount, PHP_EOL;
} catch (OsintcatApiException $e) {
    if ($e->getCode() === 429) {
        echo 'Daily allowance used up, or too many requests: try again later.', PHP_EOL;
    } else {
        // the body carries error, message, error_id and request_id
        echo $e->getCode(), ' ', json_encode($e->getBody()), PHP_EOL;
    }
}
```

</Step>

## Retries and timeouts

The SDKs do not retry on their own. A lookup retried after a timeout may already have been counted or charged, and `429 LIMIT_REACHED` cannot succeed before the allowance resets at 00:00 UTC, so you decide when to try again. TypeScript and Python requests time out after 60 seconds; in Go pass a context with a deadline, and in PHP set `timeout` in the client options.

## Upgrading from osintcat 1.x

Versions 1.x of the npm package were an older client that no longer works with the API. Version 2 is the SDK described here: `npm install osintcat@latest`.
